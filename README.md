# T.C. Reklam Arası Sessize Alma Anayasa Mahkemesi

> Televizyon reklamı başladığı anda kumandaya uzanan elin anayasal meşruiyetini, milisaniye cinsinden yargılayan ulusal üst yargı organıdır.

Bu yazılım şaka değildir. Şaka olsaydı reklam bitmeden karar çıkardı. Çıkarmıyor. Çünkü ciddiyiz.

## Yetki ve Görev

Mahkeme şunları inceler:

1. Reklamın başlama anı ile sessize alma anı arasındaki süre.
2. Elin koltuk altına, minder arkasına veya evrenin arka cebine gidiş süresi.
3. "Bir dakika şu reklam bitsin" diyenlerin vatandaşlık durumu.
4. Sessize alma hakkının temel hak olup olmadığı. (Spoiler: mahkemeye göre evet, kanala göre hayır.)

## Kuruluş

```bash
python3 mahkeme.py
```

Python 3 yeter. Bağımlılık yoktur. Adalet de yoktur. Karar vardır.

## Örnek Duruşma

Program sizi jüri, sanık ve savcı yapar. Üçü de sizsiniz. Bu, usul ekonomisidir.

Karar çeşitleri:
- **KABUL**: 1.4 saniyeden önce sessize aldınız. Anayasa gülümsedi.
- **RET**: Reklamın yarısını izlediniz. Mahkeme üzgün, reklam mutlu.
- **ERTELEME**: Kumanda bulunamadı. Dava 2029'a kaldı.
- **TAZIYE**: Reklam aslında diziymiş. Özür dilemez.
